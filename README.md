# React + Vite


An application with 3 "pages" created using rect-router navigation.
The app can be used at three modes of complexity: a regular to-do list, a list of tasks by area of life, 
and a strategy for achieving life goals.
Currently, the simple level and part of the intermediate level of planning complexity are ready.

Functionality

Easy mode

Adding and deleting tasks in the to-do list
Crossing out completed tasks with a click
Sending completed tasks to the completed tasks list with a double click
Deleting tasks from the to-do list and completed tasks list

Medium Mode

Adding and deleting task blocks by category - area of life
Adding and deleting tasks in the to-do list for each category
Adding and deleting tasks in the completed tasks list

Installation

Clone using the web URL: https://github.com/pusliaMary/Progress.git

Install the project: npm i
